# Реализованные улучшения проекта Telegram Mood Analysis

## ✅ Реализовано полностью

### 1. Статистическая валидация метрики (Пункт 1)
**Файл:** `mood_analysis.py` (встроенные функции)
- **Альфа Кронбаха** (`cronbach_alpha`) — оценка внутренней согласованности шкалы
- **PCA/факторный анализ** (`factor_analysis_pca`) — проверка структуры конструкта
- **Корреляционный анализ** (`correlation_matrix`) — взаимосвязи сигналов
- **Комплексная валидация** (`validate_mood_metric`) — объединённый отчёт
- **Вывод отчётов** (`print_validation_report`) — интерпретация результатов

### 2. Детекция точек изменения (Пункт 2)
**Файл:** `mood_analysis.py` (функции `detect_change_points`, `add_change_points_to_chart`)
- **Алгоритм PELT** через библиотеку `ruptures` — поиск статистически значимых точек изменения
- **T-test для значимости** — проверка различий между сегментами
- **Визуализация на графике** — вертикальные линии с аннотациями
- **Консольный отчёт** — даты, p-value, направление изменения

### 3. Бутстрэппинг и доверительные интервалы (Пункт 3)
**Файл:** `stats_engine.py` + интеграция в `mood_analysis.py`
- **Функция `calculate_daily_stats`** — расчёт CI для каждого периода
- **1000 итераций бутстрэпа** — надёжная оценка неопределённости
- **95% доверительный интервал** — визуализация «облака» вокруг тренда
- **Стандартная ошибка** — дополнительная метрика точности
- **Опция `--no-bootstrap`** — отключение для ускорения

### 4. Семантическое взвешивание сообщений (Пункт 4)
**Файл:** `stats_engine.py` (функция `semantic_weighting`)
- **Расстояние от нейтрали** — более эмоциональные сообщения получают больший вес
- **Нормализация весов** — диапазон [0.1, 2.0] для стабильности
- **Интеграция с LLM** — использование эмбеддингов для расчёта

### 5. Контекстуальные эмбеддинги LLM (Пункт 5)
**Файл:** `llm_analyzer.py`
- **Модель:** `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`
- **10 метрик через косинусное сходство:**
  - sentiment, anxiety, stress
  - i_focus, we_focus, future_orientation
  - social_breadth, initiative, lexical_diversity, questioning
- **Кэширование в SQLite** — повторный запуск мгновенный
- **Батчинг (batch_size=32)** — оптимизация производительности
- **Прогресс-бар** — отслеживание прогресса обработки
- **Опция `--use-llm`** — включение LLM-анализа

## 📊 Новые возможности анализа

### Научная строгость
- **Доверительные интервалы** показывают, какие изменения статистически значимы
- **Альфа Кронбаха > 0.7** подтверждает надёжность композитной метрики
- **PCA** демонстрирует, что сигналы измеряют единый конструкт «настроение»

### Объективность
- **Change Point Detection** заменяет субъективные вехи алгоритмическими
- **PELT** находит точки изменения с p-value < 0.05
- **Бутстрэппинг** количественно оценивает неопределённость

### Точность
- **LLM-эмбеддинги** улавливают иронию, сарказм, контекст
- **Семантические веса** усиливают сигнал эмоционально насыщенных сообщений
- **Перспективная коррекция** снижает вес негатива о третьих лицах

## 🚀 Использование

### Базовый запуск (лексиконный анализ)
```bash
python mood_analysis.py --json DataExport/result.json
```

### С LLM-анализом (контекстуальные эмбеддинги)
```bash
python mood_analysis.py --json DataExport/result.json --use-llm
```
*Первый запуск: ~50-100 сообщений/сек, повторный: мгновенно (кэш)*

### Без бутстрэппинга (для скорости)
```bash
python mood_analysis.py --json DataExport/result.json --no-bootstrap
```

### Из SQLite базы
```bash
python mood_analysis.py --db messages.db --user-name "Имя"
```
